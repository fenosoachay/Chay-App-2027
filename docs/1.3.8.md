## Ordre de déploiement (à valider avant exécution)

Tunnel ouvert dans une fenêtre à part : `ssh -N -L 8092:127.0.0.1:8090 $SERVEUR`. Saisie masquée des identifiants **superuser** (comme pour les lots précédents) :

```powershell
cd C:\Users\CHAY VERSET\Desktop\Chay-App-2027-migration
$env:PB_URL = "http://127.0.0.1:8092"
$env:PB_EMAIL = Read-Host "E-mail superuser"
$s = Read-Host "Mot de passe superuser" -AsSecureString
$b = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($s)
$env:PB_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($b)
[Runtime.InteropServices.Marshal]::ZeroFreeBSTR($b); Remove-Variable s, b
```

1. **Fichiers serveur** : copier `pb_hooks/bible_audio.pb.js`, `pb_hooks/bible_nettoyage.pb.js` (nouveau), `pb_hooks/lib/nettoyageBible.js` (nouveau), `pb_hooks/lib/televersement.js`. Redémarrer PocketBase ; le journal annonce toujours **6 tâches planifiées**. À partir de là, plus aucun audio Psaumes ne peut être ajouté.
2. **Nettoyage des Psaumes — simulation** (ne supprime rien) :

   ```powershell
   node pocketbase/scripts/nettoyer-psaumes.mjs
   ```

   Affiche : nombre de fiches (attendu : 146), nombre et taille des objets R2 sous `videos/bible/psaumes/` (souvent un peu plus que 146 : anciens fichiers remplacés), fiches dont l'objet manque déjà, fiches pointant ailleurs (fiche supprimée, fichier laissé tel quel), 5 exemples de clés. **Me transmettre cette sortie pour validation.**
3. **Nettoyage — suppression**, une fois les nombres validés (146 = nombre de fiches lu à l'étape 2) :

   ```powershell
   node pocketbase/scripts/nettoyer-psaumes.mjs --appliquer --confirmer 146
   ```

   - Écrit d'abord une sauvegarde des fiches : `C:\Temp\bible-psaumes-sauvegarde.json` (id, chapitre, adresse, taille, durée) ; option `--sauvegarde <fichier>`.
   - Refuse si le nombre de fiches n'est plus 146, ou si les fiches ou objets ont changé depuis la simulation (409).
   - Supprime les objets R2 (chaque suppression est vérifiée), puis chaque fiche dont l'objet a bien disparu. Rien d'autre n'est touché : ni les Proverbes, ni les vidéos, ni un fichier hors de `videos/bible/psaumes/`.
   - En cas d'erreur partielle (code de sortie 2) : relancer la simulation, puis la même commande avec le nouveau nombre ; seul le reste est traité.
   - Contrôle : relancer la simulation → « Fiches BibleAudio à supprimer : 0 », « Objets R2 à supprimer : 0 ».
4. **Migration du schéma** (refusée tant qu'il reste une fiche Psaumes) :

   ```powershell
   node pocketbase/scripts/migrer-1-3-8.mjs
   node pocketbase/scripts/migrer-1-3-8.mjs --appliquer
   ```

   La simulation annonce : `BibleAudio.book : valeurs ["proverbes","psaumes"] -> ["proverbes","ecclesiaste"]` et `BibleAudio.chapter : maximum 150 -> 31`. Relancée : « Déjà à jour ».
5. `Remove-Item Env:PB_PASSWORD, Env:PB_EMAIL, Env:PB_URL`
6. **Site**, puis **APK 1.3.8** (aucun changement natif), puis l'annonce de version (panneau admin › Équipe).
7. **Audios de l'Ecclésiaste** : avec un compte **admin de l'app** (voir `docs/1.3.7.md`), simulation puis envoi :

   ```powershell
   node pocketbase/scripts/envoyer-bible-audio.mjs .\Ecclesiaste
   node pocketbase/scripts/envoyer-bible-audio.mjs .\Ecclesiaste --appliquer
   ```

Réglages : aucun (Caddy, R2, variables d'environnement inchangés). Le dossier `Ecclesiaste\` du dépôt n'est pas suivi par git : penser à l'ajouter au `.gitignore` comme `Proverbes\` et `Psaumes\`.

## Pendant la transition

- Entre les étapes 1 et 6, l'app 1.3.7 affiche encore « Psaumes » (vide après l'étape 3) et pas l'Ecclésiaste ; l'APK 1.3.7 ignore les fiches Ecclésiaste (livre inconnu pour elle) tant qu'elle n'est pas mise à jour.
- Les Proverbes ne sont jamais touchés.
